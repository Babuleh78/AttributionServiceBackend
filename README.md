# Лабораторная работа 1

## Задание
Разработать веб-приложение для просмотра услуг и управления заявками без использования БД и JavaScript.

## Основные требования
- **3 страницы**: список услуг, детали услуги, состав заявки
- **Поиск** услуг по одному полю (сохранение параметров)
- **Коллекции в памяти**: услуги и заявки (без БД)
- **Minio** для хранения изображений (название = id услуги)
- **Адаптивный дизайн** (2-4 колонки) на основе существующего сайта
- **3 цвета** с кодами + hover-эффекты
- **Без JavaScript** - только HTML/CSS + backend

## Страницы
1. **Главная**: карточки услуг (название, цена, изображение) + карточка заявки с количеством
2. **Услуга**: подробная информация + описание
3. **Заявка**: состав заявки с услугами в строку + поле количества

## Технологии
- Backend: Django (Python) или Go
- Хранение: коллекции в памяти
- Изображения: Minio
- Стили: отдельный CSS-файл

## Критерии
 3 работающие страницы с дизайном
 Поиск и фильтрация
 Интеграция с Minio
 Отображение количества в заявке
 Соответствие дизайна образцу
