Веб-сервис для системы заявок и услуг
Цель работы
Создание RESTful веб-сервиса для бэкенд-системы управления заявками и услугами с интеграцией с БД и Minio для хранения изображений.

Основные функциональности
Домен Услуг
GET список услуг с фильтрацией

GET получение конкретной услуги

POST добавление новой услуги (без изображения)

PUT редактирование услуги

DELETE удаление услуги (с удалением изображения из Minio)

POST добавление/замена изображения услуги

Домен Заявок
GET корзина пользователя (черновая заявка)

GET список заявок с фильтрацией по дате и статусу

GET детальная информация о заявке с услугами

PUT редактирование полей заявки

PUT формирование заявки создателем

PUT завершение/отклонение заявки модератором

DELETE удаление заявки

Домен Связей М-М
DELETE удаление услуги из заявки

PUT изменение количества/порядка в заявке

Домен Пользователей
POST регистрация нового пользователя

GET информация пользователя (личный кабинет)

PUT обновление данных пользователя

POST аутентификация

POST деавторизация

Технические особенности
RESTful API с соответствующими HTTP методами и статусами

Фильтрация данных на бэкенде для заявок и услуг

Интеграция с Minio для хранения изображений услуг

Бизнес-логика статусов заявок с контролем переходов

ORM для работы с базой данных

Автоматическое вычисление системных полей (даты, статусы, модераторы)

Тестирование
Для демонстрации будет предоставлена коллекция из 21 запроса в Postman/Insomnia, покрывающая все основные сценарии работы системы.
