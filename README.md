**Readme — Лабораторная работа №4**


### Цель работы

Завершение реализации бэкенда для одностраничного веб-приложения (SPA) с поддержкой полноценной системы аутентификации и авторизации. В рамках лабораторной работы реализуются следующие ключевые компоненты:

- Аутентификация и регистрация пользователей через REST API.
- Хранение сессий с использованием **Redis** и управление через **HTTP-куки**.
- Альтернативная поддержка аутентификации через **JWT** (для использования в Postman/Insomnia).
- Интеграция **Swagger UI** для документирования и тестирования API.
- Реализация ролевой модели: **гость**, **создатель заявки**, **модератор**.
- Контроль доступа к методам API в зависимости от роли и состояния аутентификации:
  - Гость — только чтение (GET-запросы).
  - Создатель — управление своими заявками.
  - Модератор — полный доступ, включая завершение заявок и управление услугами.
- Автоматическое привязывание пользователя к создаваемой заявке.
- Подготовка технического задания (ТЗ), диаграмм (включая sequence-диаграмму бизнес-процесса) и расчёта аппаратных требований.

---

### Основные технологии

- Backend: **Python (Django REST Framework)**
- Аутентификация: **сессии + Redis** 
- Документация API: **Swagger**
- Тестирование: **Postman**, **браузер в режиме инкогнито**
- Хранилище сессий: **Redis**
- Формат отчёта: **.doc (РПЗ)** с титульным листом, диаграммами, ТЗ и таблицей методов

---

### Результат

Полностью функционирующий бэкенд с защищёнными маршрутами, готовый к интеграции с фронтендом и соответствующий требованиям безопасности, документирования и масштабируемости.
